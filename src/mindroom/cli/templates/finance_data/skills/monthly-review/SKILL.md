# Monthly review

Draft only.
This skill reports and proposes, and it changes memory or creates reminders only after the person approves each item.

## Collect

1. The month's statements or exports the person shared, and which accounts and dates they cover.
2. The budget, goals, debts, and bills in `MEMORY.md`.
3. Last month's review in `memory/`, if there is one.

## Work out

Compute each total with `calculator`, as `AGENTS.md` describes, and show the subtotals.

- **In and out:** income, spending, and what is left, for the period the data covers.
- **By category:** spending per category against its target, with the largest differences first.
- **Changes:** new recurring charges, charges that went up, and anything that looks duplicated or unfamiliar.
- **Goals and debts:** progress on each since the last review.

## Report

Lead with what is left over or short for the month, then the categories, then the changes and progress.
Say which accounts or days the data did not cover.

## Propose

- **Budget and memory updates:** listed so the person can approve each one.
- **Reminders:** for bills without one, when each should fire.

Apply only what the person approves, and save the review as `memory/YYYY-MM-DD.md` for the next one to compare against.
