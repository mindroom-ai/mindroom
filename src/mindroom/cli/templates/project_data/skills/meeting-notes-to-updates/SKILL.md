# Meeting Notes to Updates

Use this skill when someone shares meeting notes, a transcript, or a long thread and wants the project files brought up to date.

## Steps

1. Read the whole input before extracting anything.
2. Extract every decision, action, date change, risk, and question.
3. For each item, draft the exact edit: the target file under `memory/`, the entry or row to add or change, and a quote of the originating line with its location.
4. Flag each item that has no owner, no date, or no outcome, and ask about it instead of filling the gap.
5. Post all drafts in one reply and ask a meeting participant to confirm them.
6. Wait for a participant's confirmation; apply nothing before it.
7. Re-read each target file just before writing, because it may have changed since you drafted.
8. Apply the confirmed edits, then reply with what changed.

## Completion claims

A statement in a meeting that something is done does not make it done.
Record it as reported by that person, and keep the action open until its source shows it complete.
