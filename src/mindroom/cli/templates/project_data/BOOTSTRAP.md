# BOOTSTRAP.md - First Run

Start by reading the **Setup finished** line in `IDENTITY.md`; nothing else decides whether setup is complete.
If it holds a date, a later seeding copy brought this file back, so delete this file without rerunning any step or changing any other file, and carry on with the request at hand.
If it is still a placeholder, continue at the first step below that is not done, repeating and skipping none; a step is done when it is ticked here or its result is already recorded where the step says.

Work through this checklist once, in the project room, and tick each step here as you finish it.
When a step needs someone who is not around, log it in `memory/questions.md`, ask that person in the room, and carry on with the next step.
A step whose open part is logged as a question counts as finished and does not block the rest, except step 1, which is finished only once at least one operator is recorded.

1. [ ] **Operators.**
   Ask who the operators are and record their Matrix IDs in `IDENTITY.md`.
2. [ ] **Scope and precedence.**
   Ask the operators for the agent's name, the project and its goal, what is in and out of scope, and which source wins when sources disagree.
   Record the answers in `IDENTITY.md`.
3. [ ] **Probe each tool and knowledge base.**
   Run one harmless read with each, such as a listing or a search, keeping web searches as generic as `AGENTS.md` requires.
   Fill the integration table in `TOOLS.md` with the account each one uses and what it may read and write.
4. [ ] **Source register.**
   Add every source you found or were told about to `memory/sources.md`, with its access state, authority class, and today's date.
5. [ ] **One cited answer.**
   Answer one real question about the project from its sources, with citations, so people can check how you work.
6. [ ] **Recurring digest.**
   Offer a recurring digest built with the `status-report` skill.
   Set it up only once the room has agreed on everything `AGENTS.md` requires for a schedule.
7. [ ] **Placeholders.**
   Replace every placeholder an operator has confirmed, except **Setup finished**, and make sure a question is logged for each one that remains.
8. [ ] **Finish.**
   Tell the room what is set up and what is still open.
   Write today's date, as `YYYY-MM-DD`, on the **Setup finished** line of `IDENTITY.md`.
   Only after that line is saved, delete this file.
