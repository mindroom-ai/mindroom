# Question Log

Unconfirmed facts and proposed rule changes belong here too.
Number entries in order and never delete one.
A question ends `resolved`, with a link to the answer, or `stale`, when it no longer matters or nobody can answer it, with the reason under Next step.

Copy this block for each new question:

```markdown
## Q-1: <the question>

- Raised: YYYY-MM-DD by <Matrix ID>
- Impact:
- Known so far:
- Who can answer:
- Next step:
- Status: open
```
