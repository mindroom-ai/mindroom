# Tracker

## Actions

Status is `open`, `in progress`, `blocked`, `done`, or `dropped`.
Mark an action `done` only when its source shows it complete.

## Risks

Impact and likelihood are each `low`, `medium`, or `high`.
The trigger is the observable sign that the risk is turning into a problem.

Copy this block for each new risk:

```markdown
### R-1: <the risk>

- Impact / likelihood:
- Owner:
- Mitigation:
- Trigger:
- Review by: YYYY-MM-DD
```

## Milestones

Baseline is the agreed date and stays fixed unless the team rebaselines; forecast is the current expectation.
