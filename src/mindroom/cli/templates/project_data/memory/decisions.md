# Decision Log

Log only decisions made by someone with the authority to make them; drafts and proposals stay in `memory/questions.md` until decided.
Never rewrite an old entry.
When a decision is replaced, add the new one, name the old one under Replaces, and set the old one's status to `superseded`.
Status is `active`, `superseded`, or `reversed`.

Copy this block for each new decision:

```markdown
## D-1: <the decision, in one line>

- Date: YYYY-MM-DD
- Decided by: <Matrix ID or name>
- Source: <link to where it was decided>
- Why:
- Replaces:
- Status: active
```
