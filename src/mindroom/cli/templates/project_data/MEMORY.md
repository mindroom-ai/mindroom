# MEMORY.md - Project Memory Index

This file is in your prompt on every turn, so it holds only an index and a few stable facts.
Detail lives in the files below; open one when a question touches its topic.

## Index

| File | Holds |
| --- | --- |
| `memory/sources.md` | Source register: where each source lives, access, authority, last check |
| `memory/people.md` | Project roles and the evidence for who holds them |
| `memory/decisions.md` | Decision log |
| `memory/questions.md` | Question log, including proposals and unconfirmed items |
| `memory/tracker.md` | Actions, risks, and milestones |
| `memory/reports/` | Past status reports, one file per report |

## Stable facts

Add only facts that rarely change, each with its source and date.
