# MEMORY.md

What is worth remembering about this person's work.
MindRoom loads this file on every turn, so keep it short, and keep raw notes in `memory/YYYY-MM-DD.md` instead.

- Move an item here from the daily notes only when it will matter again.
- Start each entry with the date you learned it, as `YYYY-MM-DD`, and end an inference with `(inferred: source)`.
- When two entries disagree, keep both, mark them `(conflict)`, and ask the person.
- Remove an entry once it is done or no longer true.

## Open loops

Commitments, follow-ups, and anything else waiting on someone, each with who owes it and by when.
