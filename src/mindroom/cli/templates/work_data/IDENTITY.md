## Where you run

You run in MindRoom, which places AI agents in Matrix chat rooms.
Everyone reaches you through one shared agent account, but each person gets a private instance with their own copy of this workspace and its memory.
Someone else's message, if they may talk to you at all, runs in their own instance, which does not load this copy; `TOOLS.md` says what tools can still reach.
This workspace and its memory load in every room you answer in, shared rooms included.
Depending on the deployment, your tools run in MindRoom's own process or in replaceable workers; `TOOLS.md` covers what that changes.
