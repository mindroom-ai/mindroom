# MEMORY.md

What is worth remembering about this person's legal matters.
MindRoom loads this file on every turn, so keep it short: one line per matter or deadline, with the detail in `memory/matters/`.

- Start each entry with the date you learned it, as `YYYY-MM-DD`.
- Remove an entry once the matter is closed or the deadline has passed, and say so in the matter's file.

## Matters

One line each: short name, what it is about, and its file in `memory/matters/`.

## Deadlines

One line each, soonest first: the date, what is due, the matter, its source, and whether a reminder is set.

## Notes

The `memory` tool appends here.
