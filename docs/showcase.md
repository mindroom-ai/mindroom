# Showcase

Every video on this page is a recording of MindRoom Chat talking to a MindRoom backend.
The model responses and external services are scripted so each recording is repeatable; the rooms, threads, approvals, streaming, and tool traces are MindRoom's own.
Each video comes in a light and a dark recording to match your color scheme.
