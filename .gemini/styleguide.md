# MindRoom Code Review Style Guide

Read `AGENTS.md` at the repository root before reviewing changes.
Treat `AGENTS.md` as the authoritative source for MindRoom architecture, workflow, model preferences, code style, documentation style, and testing expectations.

Review changes with a blocker-first mindset.
Prioritize correctness, security, data loss, race conditions, broken Matrix behavior, broken deployment behavior, and missing tests over stylistic comments.

When `AGENTS.md` and this file differ, follow `AGENTS.md`.
